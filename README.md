# 新云传媒户外提案台

面向 2027 年上海户外媒体投放的交互式 HTML 原型。现场可换行业、预算、媒体和档期，查看预算差异，打开逐项依据，或移除一个点位后重新配案。

## 运行

双击 `提案台.html`，用 Edge 或 Chrome 打开。单文件包含样例目录、规则、图表和 Excel 导出库，可离线运行。

从源代码生成页面需要 Node.js 20 或更高版本。

```powershell
node scripts/build.cjs
node --test tests/planner.test.cjs
```

需要在同一网络内提供评审预览时，可把生成的 HTML 交给静态托管，或从仓库目录运行 `python -m http.server 8765 --bind 127.0.0.1` 并以 `http://127.0.0.1:8765/提案台.html` 在本机访问。

## 演示顺序

1. 打开星巴克示例。默认 200 万，公交车身与地铁出入口，2027-06-01 至 2027-06-30。核心到店点是南京西路上海烘焙工坊。
2. 点击圈选地图的门店或商圈，再看媒介清单。点击一条资源，查看它的档期、可用量、覆盖依据和刊例推导。
3. 切 100 万或 500 万，观察素材场景和核心圈选如何保留，以及媒体数量、预算余量和组合变化。评委可直接指定另一个行业、媒体或档期。
4. 切到「档期核验」，展示核验规则和当前数据缺口。导入两个比赛系统的匹配数据后会即时重算。
5. 「导出方案 HTML」生成锁定本次输入、可继续筛选的客户版本。「导出 CSV / Excel」用于后续沟通、排期和核价。

随包的现场版预置星巴克默认档期数据。截至 2026-11-21，红豆公交文件有 431 条导出记录，另从地铁库核对 20 条出入口。新云大数据覆盖分析以南京西路 789 号、静安寺、上海人民广场、上海新天地为中心，统一使用 500 米，平台返回 40 条媒体。公交按线路匹配，地铁覆盖结果仅到站级。红豆给出实际出入口编号和空位。由于缺少实际计价面积及出口级覆盖，地铁候选只进入策略测算。

复现核验示例时，在现场版选择「食品饮料 · 星巴克」，保留 2027-06-01 至 2027-06-30 并切到「档期核验」。200 万预算滚动到 31 辆公交（15 条线路记录），按刊例中值测算 198.25 万元。策略测算含两处地铁备选，具体测算与证据可逐项点开。

## 如何刷新真实数据

| 来源 | 获取方式 | 导入要点 |
| --- | --- | --- |
| 红豆媒体库 | 在公交或地铁库查询完整目标投放窗，按系统空车数导出 | 导入时选择同一实际查询起止日及导出日期。需要资源名称、空车数、级别。普通地铁口另需实际面积 |
| 新云可视化平台 | 按地标和半径查覆盖，分别导出公交、地铁候选 | 导入时选择相同圈选中心、半径和媒体类型。跨媒体文件可用「媒体」列逐行指定 |
| 可视化平台媒体查询 | 选 2023 年有效月份，获取历史人流 | 可在覆盖模板补入历史月份、指标名和数值，逐个地标查看 |
| 可视化平台 AI 线路 | 对候选线路生成平台授权预览链接 | 可填入覆盖模板的「AI线路链接」，打开后使用平台的线路交互 |

- 支持 XLSX、XLS、CSV。导入对话框可下载两种标准模板。对未识别的字段，把原表数据映射至模板列。多中心的覆盖表按资源和中心拆行，普通地铁口核实到具体出口后再加入模板。空位数以红豆字段为准。
- 匹配优先用两边一致的资源 ID。缺 ID 时以媒体类型与标准化名称匹配，必要时用形式、运营公司消除歧义。名称有多个候选时保留待核。含混的地铁站名或聚合资源应补具体出入口与唯一资源 ID，避免重复占用。
- 仅完整、相同的查询窗口能进核验模式。资源随导入逐项更新，较新快照覆盖相同窗口同资源，零空位覆盖旧值。快照不锁档。签约前重新查询。
- 导入只保存当前浏览器本地数据。需要把组织方明确允许流转的核验数据预置进现场离线包时，用 `data/verified.local.json`（字段与导入后的结构一致）单独构建。该文件在 Git 中忽略。日常演示可直接导入，无需修改文件。

## 方案与价格

- 行业默认品牌为招商银行、星巴克、上海第一医药、上海和睦家、上海迪士尼度假区。品牌事实页链接随方案展示。2027 年活动为演示 brief，团队可按目标品牌调整 `src/catalog.js` 的受众、承接动作、地标和权重。
- 组合先按场景比例测试公交与地铁，再将可用余额加配。新增圈选优先，重复覆盖的边际权重逐步递减。同一组参数可复算。排序是可解释的贪心推荐，可能留有余量。
- 刊例来自资料 07。区间低位、中值、高位可切换。默认中值，发布费按 100% 刊例测算，折扣可调。制作另计。普通地铁候选的策略演示面积为每处 60 ㎡，实盘按实际面积。已知的独立陆家嘴 6 号口、8 号口及人民广场 16 号口优先使用指定刊例。形式和口径不明的资源不做实盘报价。
- 公交台账是 2026-11-13 单日的静态参考。策略测算中的圈选关联、地铁出口候选、等级和面积需在比赛系统复核。示意图用于路演导航。历史人流保持原指标，原型不汇总为 2027 年曝光承诺。
- 报价按起始日逐月，未满一月进位，以月刊费乘月数及折扣加制作费。预算比较基于所选价格情景。若同组合按区间上限可能超预算，页面直接显示差额。税费、施工与折扣口径由销售最终确认。

## 团队交付

一页说明见 `一页纸说明.pdf`。可编辑 HTML 位于 `docs/one-page.html`。比赛数据的操作入口只指向红豆和新云大数据平台。品牌事实使用公开材料。代码不包含比赛账号、密码、业务会话、合同或占用明细。

实际运行的配案是规则引擎。AI 已用于辅助拆解活动、撰写策略初稿和构造测试用例，平台的 AI 线路图通过业务导出链接使用。没有运行时外部模型调用。

SheetJS CE 0.20.3 用于本地表格解析和生成，许可证位于 `vendor/SheetJS-LICENSE.txt`。
